# ⚡ نيترو (Nitro)

إضافة Chrome غير رسمية لتطبيق الويب الخاص بـ EA FC Ultimate Team، مبنية فوق أداة **Paletools** مع تعريب كامل وحذف ميزات Snipe، وأهم من ذلك: **حلّال SBC ذكي** يحل التحديات بأقل تكلفة ممكنة.

> **تنبيه:** هذا المشروع غير تابع لـ EA ولا لـ Paletools ولا مدعوم منهما. استخدامك لأي أداة تتفاعل مع تطبيق الويب قد يعرّض حسابك لإجراءات من EA. المسؤولية عليك.

## 📱 قريباً: تطبيق آيفون

نعمل على نسخة لتطبيق **iPhone** ستتوفر مستقبلاً. تابع المستودع للتحديثات.

## المميزات

### 🧩 حل SBC الذكي (التحديات العادية)
زر **«حل نيترو الذكي»** داخل أي تحدي:

- **يفهم كل شروط التحدي:** التقييم، الكيميستري (الكلي ولكل لاعب)، عدد/تنوع الدول والدوريات والأندية (أدنى / أقصى / بالضبط)، الندرة والجودة، حدود التقييم، وأرقام الدوري/الدولة/النادي المحددة.
- **الكيميستري والتقييم من حاسبة اللعبة نفسها**، وبعد الحل يتأكد من نتيجته عند اللعبة (`meetsRequirements`) ويصلح بحكمها إن رفضت.
- **الأولوية:** ناديك ← ناديك مع الغالي ← الشراء (أقل عدد وأرخص بطاقات غير مملوكة بسعر fut.gg).
- **الأقل تكلفة ثم الأقل تقييماً:** كل بطاقة بسعر السوق (حتى غير القابلة للبيع)، والشراء الفعلي يُحسب ×2، وبين الأسعار المتساوية يفضّل الأقل تقييماً.
- **استبعاد تلقائي** لتشكيلتك الفعّالة والمعارين واللاعبين الغالين (الحد قابل للتعديل).
- شروط «بالضبط/أقصى» الصعبة (مثل «دولتان بالضبط») يعالجها ببحث منظّم.
- ملخص واضح: اللاعب، التقييم، المصدر، السعر، المجموع، الشروط ✅/❌ من حكم اللعبة، وزر نسخ.
- شاشة تقدّم وزر «اكتفِ بأفضل حل الآن».

### 💎 SBC النقاط (اختيار لاعبين بالنقاط)
زر **⚡ نيترو** بجانب Auto-Select: يختار الأرخص والأقل لاعبين لتحقيق الهدف، ويقسّمه على دفعات، مع ملخص بالتكلفة والسعر لكل نقطة. وفيه «نفّذ الحل كاملاً» بضغطتي تأكيد.

### 🎛️ إعدادات مرتّبة
تبويب «نيترو» ← الإعدادات مقسّمة لأقسام (نيترو، SBC، السوق، النادي، الباكات، الواجهة، الأتمتة) مع بحث وعدّاد للخيارات المفعّلة.

### 🔌 زر تشغيل/إيقاف
من أيقونة الإضافة، وإعادة تحميل صفحة EA تلقائياً عند التبديل.

### ما تم تغييره عن Paletools
- تعريب كامل للواجهة.
- حذف Snipe / Auto Snipe (ومعها اختصارات الكيبورد التابعة له).
- إخفاء بانرات الدعم وبالونات عيد الميلاد.
- طلبات الشبكة محصورة في `fut.gg` و`futbin.com` و`futwiz.com` فقط، من دون كوكيز، ويُحجب `pale.tools`.

## التثبيت

المشروع **لا يتضمّن** كود Paletools الأصلي ولا النسخة المبنية؛ تُبنى محلياً من الملف الرسمي:

```bash
git clone <رابط المستودع>
cd <المجلد>/tools && npm install && cd ..
sh tools/update.sh
```

يحتاج Node.js. ينزّل آخر نسخة رسمية، يبني النسخة العربية، يشغّل الاختبارات، وينتج `out/extension/`.

ثم في Chrome:

1. افتح `chrome://extensions` وفعّل **Developer mode**.
2. **Load unpacked** ← اختر المجلد `out/extension`.
3. عطّل Tampermonkey أو أي نسخة Paletools ثانية.
4. افتح EA FC Web App وأعد تحميل الصفحة.

بعد أي إعادة بناء: اضغط زر إعادة التحميل على بطاقة الإضافة في `chrome://extensions`.

## التحديث

```bash
sh tools/update.sh
```

البناء يفشل برسالة واضحة إن غيّر Paletools كوده بشكل يكسر أي تعديل (كل تعديل يُطبَّق مرة واحدة بالضبط)، والنصوص الجديدة غير المترجمة تُطبع بعد البناء.

## هيكل المشروع

| المسار | الوصف |
|---|---|
| `tools/build.js` | يبني سكربت المستخدم من الملف الرسمي (فك التشفير، الترجمة، الحذف، التعديلات) |
| `tools/make-extension.js` | يحوّل السكربت إلى إضافة Chrome (MV3) |
| `tools/ar.json` / `tools/config.json` | الترجمة العربية والإعدادات (الاسم، الإضافات المحذوفة…) |
| `tools/nitro/sbc.js` | حلّال SBC العادي (التحليل الكامل للشروط، البحث، الشراء، التحقق من اللعبة) |
| `tools/nitro/points.js` | حلّال SBC النقاط |
| `tools/nitro/solver.js` | الأدوات المشتركة: التسعير، الملخصات، ربط Smart Builder |
| `tools/nitro/settings.js` | صفحة الإعدادات المعاد تصميمها |
| `tools/extension/` | ملفات الإضافة: popup، background، bridge |
| `tools/brand/` | الشعار والأيقونات |
| `tools/test-*.js` | الاختبارات (وحدات، إضافة، وتكامل على لعبة وهمية) |

## الاختبارات

```bash
node tools/test-nitro.js
node tools/test-sbc-integration.js
node tools/test-extension.js out/extension
```

تُشغَّل كلها تلقائياً ضمن `sh tools/update.sh`.
